# MDN Tech brand assets

Redrawn logo mark (2026-08-16) — clean vector replacement for the old auto-traced SVG.
Concept: the website's black-hole signature (lensing halo above, event-horizon core,
edge-on accretion disk) kept HORIZONTAL — the diagonal tilt of the old icon usage is
what made it read as the Grok slashed-O. Thin inner circle removed, replaced by a
solid core with a thin negative-space photon-ring gap.

| File | Use |
|---|---|
| `mdn-mark.svg` | Primary mark, purple gradient — dark backgrounds (OG images, LinkedIn logo/banners, hero) |
| `mdn-mark-mono.svg` | Single-color mark, `currentColor` — navbar, footer, anywhere inline (inherits CSS color; renders black via `<img>`) |
| `mdn-mark-simple.svg` | Simplified variant (no core) — favicons and sizes under ~32 px where the photon-ring gap closes up |

Colors: gradient `#EDE9FE -> #A855F7 -> #6D28D9` (matches site hero violet).
Mono on light: `#221B3A`. Mono on dark: `#F4F2FF`.

Aspect ratio ~1.9:1 (wide). In square containers (LinkedIn 300x300, favicons)
scale the mark to ~70-75% of canvas width and center vertically.
